# ComfyUI HTTP API for procedural game asset generation

Game sprites (ships, admiral portraits) are generated via ComfyUI's HTTP API called from Claude Code skills (`/gen-ship`, `/gen-admiral`, `/gen-image`). SDXL is the base model; IP-Adapter provides style consistency from `inspo/` reference images; ControlNet Canny guides silhouette from a shape reference. A Python script (`scripts/comfyui_submit.py`) handles submission, polling, rembg background removal, and file save — the skills stay thin.

We picked this over contracting an artist or using a hosted service (Midjourney, DALL-E) because it integrates directly into the dev workflow, generates assets programmatically with consistent style across all hull classes, keeps everything local and offline, and produces output directly into `client/assets/` without manual copy-paste. The trade-off is upfront tooling cost and lower ceiling on artistic quality compared to a human artist — acceptable for a pre-alpha where iteration speed matters more than polish.
